# HR Build Day 데모 — 독립 검증 종합

## 판정

**부분 확인 / 실행 검증 차단 / 전체 수용 기준 미충족.** 현재 안전하게 설명할 수 있는 범위는 가상 HR 데이터 기반의 정적 인원·TO·월말 예측 시연이다. 전체 실시간 HR SaaS 완성, 실제 권한별 격리, 자동 메일, Fable 5.1 실행 완료를 주장할 수 없다.

## 검증 방법과 결과

- 독립 검토 2개 역할: 데이터·산식 / 요구사항·문서·화면. 결과를 모두 회수했다. 두 역할이 모두 실행 테스트를 완료한 것은 아니다.
- 데이터 검토: 생성기 전체 소스 검토 완료. 격리 실행 준비 명령이 도구 승인 만료로 차단되어 원본 실행 0회, 독립 재계산 0회. 재시도·우회 없음. data-audit.md 및 validation.json은 생성되지 않았다.
- 요구사항 검토: coverage-audit.md 작성 확인. 정적 소스 검토이며 일부 HTML 긴 줄이 잘려 전체 HTML 검토에는 제한이 있었다.
- 총괄 브라우저 확인: 실제 기존 HTML 로드 및 DOM 대사 완료. 조직 11개, TO 422, 현재 406, 입사 19, 퇴사 14, 월말 411, Gap -11. 행별 현재+입사−퇴사=월말 및 월말−TO=Gap 위반 0. 이는 화면 내부 대사이며 원천 파일과의 일치 증거가 아니다.

## 외부 시연 전 보완할 사항

1. 소개·명세 문서는 온보딩/Q&A/follow-up을 설명하지만 현재 구현은 인원·TO·월말 예측 중심이다. 팀장 요청 범위에 맞게 정렬하거나 제품 비전과 이번 구현을 분리해야 한다.
2. 역할별 뷰는 설명 카드다. 로그인·역할별 인가·조직 범위 제한이 구현됐다고 표현하지 않는다.
3. 실시간 갱신·월초 자동 발송은 미구현이다. 정적 스냅샷과 이메일 목업으로 표시한다.
4. 정상 값과 변형 raw 값을 함께 생성하고 차이를 세는 코드는 실제 원천 클린징 파이프라인의 실행 증거가 아니다.
5. Fable 5.1 및 최초 생성 작업의 하네스 실행 증거는 미확인이다. 이번 독립 검증 하네스와 구분한다.
6. 일부 속성별 통계는 보고서/생성기에 있지만 대시보드에는 없다. 연차·직책·stage의 업무 정의도 확정해야 한다.

## 데이터 실행 재개 후 확인할 위험

다음은 소스에서 발견한 로직 위험이며 실제 발생 건수·오차는 미검증이다.

- 현재 인원은 재직자만 세지만 퇴사 예정자는 휴직자를 포함한 전체 Master에서 추출해 차감한다.
- 퇴사 예정자를 복원 추출하므로 동일 employee_id가 중복될 가능성이 있고 중복 방지가 없다.
- 입퇴사 예정일은 생성 범위에 의존하며 집계 단계 날짜 필터와 당일 반영 기준이 없다.
- 연령·경력·입사일의 독립 생성으로 총경력보다 재직기간이 길어지는 등 모순 가능성이 있다.

실제 실행과 failing case 증거를 확보하기 전 숫자 오류가 몇 건이라고 단정하지 않는다.
