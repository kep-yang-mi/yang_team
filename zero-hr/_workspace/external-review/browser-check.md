# HR 데모 브라우저 확인

- 대상: PM 작업 공간의 zero_company_hr_dashboard.html
- 방식: 실제 브라우저 file:// 로드, DOM 조회, 전체 화면 확인.
- 결과: HTML 열림. KPI 카드·조직 그룹 막대·조직별 예측 표·역할별 설명 카드 표시.
- 표시된 가상 데이터 문구: Agent-generated virtual HR data.
- 제목은 실시간 대시보드이나 실제 페이지 스크립트 0개, 버튼·선택·입력 컨트롤 0개. 실시간 입력 갱신·재계산 경로 없음.
- 역할별 뷰는 경영진·HR·경영기획팀·조직장 설명 카드이며 실제 로그인·역할 전환·접근통제 검증이 아님.

## DOM에서 실행한 표 대사

브라우저 JavaScript로 모든 조직 행을 읽어 합산하고 행별 현재+입사−퇴사=월말, 월말−TO=Gap을 확인했다.

- 조직 행: 11
- TO 합계: 422
- 현재 재직 합계: 406
- 입사 예정 합계: 19
- 퇴사 예정 합계: 14
- 월말 예측 합계: 411
- Gap 합계: -11
- 행별 두 항등식 위반: 0

이 결과는 기존 HTML 내부 숫자의 산술 일치만 검증한다. 원천 CSV와의 일치·예측 정책 적합성·생성 코드의 재현성은 별도 데이터 검증 대상이다. 동일한 요약 숫자를 여러 파일에 복사한 것은 원천 대사의 증거가 아니다.

## 화면 관찰

데스크톱 화면에서 표와 카드의 글자·대비를 읽을 수 있었으며, 역할별 영역은 페이지 하단에 카드로 나열됐다. 모바일·키보드 접근성·스크린리더 검증은 하지 않았다. 외부 서버·실제 HRIS·인증·메일 전송은 시험하지 않았다.
