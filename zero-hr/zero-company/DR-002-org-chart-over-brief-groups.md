# DR-002 조직 그룹 합계는 조직표를 정본으로 (2026-09-23)

- **제안:** 브리프 §7 "조직 그룹별 재직 인원"(Executive 10 / Build 215 / Go-To-Market 119 / Operations 62, 합 406)은 브리프 §8 조직별 표의 그룹 합(10 / 220 / 128 / 48, 합 406)과 불일치한다. 조직별 표를 정본으로 삼고, 불일치 사실을 `headcount-stats.dataQuality.briefDiscrepancies`와 월초 리포트 데이터 품질 절에 기록한다.
- **근거:** 조직별 표는 TO·입퇴사·권고까지 연결된 하위 수준 데이터이고, 그룹 합은 그것의 파생이다. 파생을 고치려 원천을 비트는 것은 대사 원칙 위반.
- **옵션:** (a) 조직표 정본 + 불일치 기록 (b) 그룹 합 정본 + 조직별 표 재배분 (c) 사용자에게 확인 후 결정
- **기본안:** (a). 사용자 확인이 오면 (c)로 갱신.
- **fallback:** 사용자가 그룹 합을 정본으로 지정하면 §2-7 표를 재배분하고 생성기 재실행.
