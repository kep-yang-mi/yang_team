# Zero Company OS: Agent-Native Company를 만드는 운영체제

일시: 2026-09-23 KST  
문맥: Claude Fable 5.1 Build Day · Everyday Theme  
작성: Yang Team OS / PM  
데이터: agent 생성 가상 HR 데이터

> Zero Company는 “회사를 만들기 위해 사람을 먼저 대규모로 고용하는 방식”이 아니라, **agent가 회사의 반복 운영 기능을 수행하고 사람이 미션·판단·관계를 담당하는 새로운 회사 운영체제**입니다. 이번 데모는 그 첫 적용 사례로, Zero Company 위에서 HR SaaS 스타트업을 만들고 실시간 HR 리포트를 agent가 직접 생성하는 과정을 보여줍니다.

---

## 1. 왜 Zero Company인가

오늘날 스타트업은 제품을 만들기도 전에 많은 운영 부담을 떠안습니다.

- 채용, 인사, 재무, 법무, 영업, 고객지원, 리포팅이 동시에 필요합니다.
- 초기 팀은 작지만, 회사가 요구하는 운영 복잡도는 이미 큽니다.
- SaaS 도구는 많지만, 실제 업무는 여전히 사람이 데이터를 모으고 정리하고 해석해야 합니다.

Zero Company의 질문은 단순합니다.

> “회사의 반복 운영 업무를 agent가 수행한다면, 사람은 더 적은 인원으로 더 큰 회사를 만들 수 있지 않을까?”

Zero Company는 이 질문에 대한 실험이자, agent-native company를 만들기 위한 운영체제입니다.

---

## 2. Zero Company의 미션

**Zero Company의 미션은 누구나 작은 팀으로도 완전한 회사를 설립·운영·확장할 수 있게 만드는 것입니다.**

이를 위해 Zero Company는 다음을 목표로 합니다.

1. **회사 운영 기능의 agent화**
   - HR, Finance, Legal, Sales, Customer Success 같은 기능을 agent가 수행 가능한 업무 단위로 나눕니다.

2. **업무 결과의 실시간 가시화**
   - agent가 수행한 업무는 문서, 로그, 대시보드, 리포트로 남습니다.

3. **사람의 역할 재정의**
   - 사람은 반복 처리자가 아니라 목표 설정자, 승인자, 관계 형성자, 최종 판단자가 됩니다.

4. **작은 팀의 확장성 극대화**
   - founder 1명 또는 소수 팀도 HR팀, 재무팀, 운영팀을 agent 기반으로 구성할 수 있습니다.

---

## 3. Zero Company OS의 핵심 Rules

Zero Company OS는 단순한 자동화 도구가 아니라, agent들이 함께 일하기 위한 운영 규칙을 가집니다.

### Rule 1. 모든 agent는 역할을 가진다

agent는 “무엇이든 하는 챗봇”이 아니라 명확한 역할을 가진 팀원입니다.

예:
- HR Reporting Agent
- Data Cleansing Agent
- Finance Planning Agent
- Compliance Review Agent
- Customer Support Agent

각 agent는 자기 역할, 입력 데이터, 산출물, 완료 기준을 가져야 합니다.

### Rule 2. 중간 발견과 실패 로그를 공유한다

여러 agent가 각자 많이 시도하는 것보다, **검증된 중간 발견과 실패 로그를 공유할 때 문제 해결 효율이 올라갑니다.**

따라서 Zero Company OS에서는 모든 실행자가 다음을 남깁니다.

- 무엇을 시도했는가
- 어떤 데이터/근거를 봤는가
- 무엇이 실패했는가
- 무엇이 검증됐는가
- 다음 agent가 어디서 이어받아야 하는가

### Rule 3. 하네스 방식으로 복잡한 업무를 나눈다

복잡한 업무는 한 agent에게 모두 맡기지 않습니다. 역할별 agent가 병렬로 수행하고, 마지막에 owner agent가 종합합니다.

이번 HR 데모에서는 다음 4개 역할로 나누었습니다.

|역할|담당 과제|산출|
|---|---|---|
|데이터 통합 agent|TO, Master, 입사자, 퇴사자 정보 통합|통합 HR 데이터셋|
|클린징 agent|부서명/조직 구조/입퇴사 일자 정규화|정제 로그|
|분석 agent|조직별/속성별 통계, 월말 예측|summary + forecast|
|배포 agent|권한별 대시보드, 월초 이메일 초안|HTML dashboard + 이메일 목업|

### Rule 4. 사람은 승인 gate를 담당한다

agent는 실행하고 제안하지만, 중요한 결정은 사람이 승인합니다.

승인 gate가 필요한 예:
- 외부 발송
- 채용/해고 관련 결정
- 민감정보 접근
- 재무 지출
- 법적 리스크가 있는 액션
- 조직 구조 변경

### Rule 5. 모든 결과는 재사용 가능한 자산으로 남긴다

일회성 답변이 아니라, 다음 실행자가 이어받을 수 있는 자산으로 남깁니다.

- Markdown 보고서
- CSV/JSON 데이터
- Dashboard HTML
- 실행 로그
- 권한별 view
- 다음 액션

## 4. 첫 번째 제품: HR SaaS 스타트업

Zero Company 위에 설립할 첫 스타트업은 HR 운영을 지원하는 SaaS입니다.

비유하면 Workday처럼 HR 데이터를 다루지만, 목표는 단순 HRIS가 아닙니다.

**Zero Company HR은 agent가 HR 운영 업무를 직접 수행하는 HR Operations Agent Platform입니다.**

### 제품 목표

HR 담당자가 매월 반복하는 다음 업무를 agent가 수행합니다.

- 조직별 인원 현황 집계
- 고용유형, 재직/휴직, 성별, 연령대 분포 분석
- 직군, 직책, 연차, stage별 구성 분석
- 총경력, 재직기간 분석
- 퇴직사유별 퇴직 구분
- TO 대비 과부족 파악
- 입사/퇴사 예정자 기반 월말 인원 예측
- 권한별 대시보드 생성
- 월초 자동 리포트 이메일 발송

## 11. 이 데모가 보여주는 것

이번 데모는 단순한 HR 리포트가 아닙니다.

이것은 Zero Company OS의 작동 방식입니다.

1. 회사의 반복 업무를 agent 역할로 나눈다.
2. agent가 데이터를 만들고 통합하고 정리한다.
3. agent가 분석과 예측을 수행한다.
4. 결과는 권한별 dashboard와 리포트로 배포된다.
5. 사람은 최종 판단과 승인, 외부 커뮤니케이션을 담당한다.

즉, Zero Company는 “AI를 쓰는 회사”가 아니라 **AI agent들이 회사 운영 기능을 구성하는 회사**입니다.
